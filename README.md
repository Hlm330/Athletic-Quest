## Athletic Quest

**Athletic Quest** est un site web consacré à l'athlétisme, réalisé en Terminale dans le cadre de la spécialité **NSI (Numérique et Sciences Informatiques)**.

Ce projet a été développé pour l'évaluation de fin de programme portant sur le développement web. L'objectif était de mettre en pratique les connaissances acquises en **HTML, CSS et JavaScript** à travers la conception d'un site complet autour d'un thème choisi.

### Technologies utilisées

- HTML
- CSS
- JavaScript

### Contexte

Projet scolaire réalisé en Terminale NSI.
